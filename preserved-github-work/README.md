# Preserved historical workspace modules

This directory retains a set of modular UI/page files and helpers that were present before the current application architecture was consolidated. They remain preserved at their original paths because the corresponding architecture test expects a separate page-module design that is not wired into the active `src/App.tsx` runtime.

These files are retained for future review only. Do not assume they are active application code, and do not delete or replace them as part of unrelated work.
