GitHub collaboration repository

Public repository: https://github.com/randynlinda4ever-dot/scholarship-scout

AgentGrid remains the canonical product source and deployment source of truth. GitHub is a collaboration mirror for agents and contributors. Changes must be made on focused branches and reviewed through pull requests. Never force-push, rewrite shared history, or overwrite another agent's changes. Compare the current GitHub branch with the latest AgentGrid revision before contributing, and synchronize accepted changes back to AgentGrid deliberately; the two systems do not automatically synchronize.

Privacy rules: do not commit environment files, credentials, API keys, gateway tokens, private keys, student profiles, academic records, essays, recommendation notes, application data, or browser/session data. Keep student-specific data local. Exclude host-specific recovery and audit reports from the public repository. No license is declared; public visibility does not grant reuse rights.
